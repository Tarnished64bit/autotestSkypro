# Автотесты для сервиса "Читай-город"

## Описание проекта
Проект содержит автоматизированные тесты для интернет-магазина "Читай-город":
- **UI тесты** - 5 тестов (Selenium WebDriver)
- **API тесты** - 9 тестов (requests)
